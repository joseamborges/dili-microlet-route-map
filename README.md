# Dili's Microlet Transport Network – Timor-Leste

An interactive map of the 13 microlet (minibus) routes in Dili, Timor-Leste, with simulated microlets moving along each route.

**View the map:** https://joseamborges.github.io/dili-microlet-route-map/

## Features

- All 13 microlet routes, each in its own color
- Simulated microlets moving along every route, with a speed control (1 s = 30 s, 1 min or 2 min)
- Click a route number to show that route on its own
- Dark map or Satellite, with optional place labels
- Zoom from Dili's streets out to all of Timor-Leste

## About the moving microlets

Dili's microlets have no published timetable or live GPS tracking, so the moving dots are a simulation. They show how the network works, not where real vehicles are.
